# 自动创作者中心同步默认轻量化

## 背景

创作者中心统计同步已经默认关闭公开正文抓取，但登录成功后的自动同步仍未显式传入 `force_light`，定时同步也会在累计若干轮后随机进入深入轮。自动流程因此可能打开笔记详情页，增加无必要的浏览器访问和风控风险。

## 目标

1. 登录成功后的自动同步只读取创作者中心概览和笔记列表，不打开逐篇详情/正文页。
2. 定时同步默认永远保持轻量模式；深入轮必须由部署配置显式开启。
3. 保留人工 API/显式调用的深入同步能力，不改变统计数据导入和持久化格式。
4. 用测试和配置文档明确自动同步与人工深入同步的边界。

## 非目标

- 不删除创作者中心统计客户端的详情/正文能力。
- 不改变扫码登录、发布、人工互动或历史数据兼容逻辑。
- 不访问主站公开笔记作为自动同步的默认路径。

## 验收标准

- `sync_after_login()` 调用 `sync_account_stats(..., force_light=True)`。
- 未设置 `CREATOR_STATS_DEEP_EVERY_N_RUNS` 时，定时轻量解析永远返回 `True`，不累计深入轮计数。
- 部署脚本和配置文档将深入轮默认值明确为 `0`，并说明只有显式设置正整数才启用。
- 相关单元测试、ruff、mypy 通过。
