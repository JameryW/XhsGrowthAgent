# 多轮全站前端体验升级

## 背景

当前工作区已经完成导航和工作流首屏优化，但所有页面仍存在明显的体验断层：页面标题层级不统一，分析/历史/设置/帮助/评估/审核各自使用不同的间距和卡片语言，加载/空状态的行动提示不一致，窄屏下信息密度和顶部操作也不统一。用户要求继续多轮优化并覆盖所有前端页面。

## 目标

- 建立全站一致的页面壳层：标题、说明、上下文、操作区和内容间距有统一规则。
- 让分析、评估、历史、审核、设置、帮助、自由创作、回放、登录、404 和 Showcase 在首屏都有明确的视觉焦点和下一步行动。
- 统一卡片、标签、空状态、加载态、错误态和移动端触控尺寸，降低页面之间的认知切换成本。
- 保留现有工作流和后端语义，所有新增文案双语，状态来源继续使用现有 Pinia/API。

## 多轮范围

1. 全局壳层：新增可复用页面标题/上下文组件，统一认证页的内容宽度、顶部节奏、响应式间距和页面背景层次。
2. 工作区页面：优化审核、分析、评估、历史、设置和帮助的标题区、筛选区、空/错/加载状态及主要 CTA。
3. 特殊页面：优化 Showcase、登录、404、自由创作 TUI 和回放页的首屏状态、操作可见性和移动端布局。
4. 交互质量：补充焦点/键盘、触控高度、减少动画、双语文案和组件回归测试。

## 非目标

- 不修改后端 API、数据库、工作流节点和路由地址。
- 不删除现有功能，不用大规模换肤替代信息层级和操作路径优化。

## 验收标准

- 所有路由页面都使用统一的页面壳层或等价的标题/上下文层级，首屏能识别页面目的和下一步动作。
- 主要空状态、加载态和错误态都提供清晰原因、恢复/继续动作；窄屏无页面级横向溢出。
- 主要按钮、标签页、筛选和移动端菜单项可键盘访问，触控高度不小于 44px；新增动画在 reduced-motion 下不隐藏内容。
- 新增文案同时存在于 `en.json` 与 `zh-CN.json`，共享组件有组件级测试。
- `npm run type-check`、`npm run test:run`、`npm run build`、`git diff --check` 通过，并部署后完成 `/`、健康端点和静态资源验收。
