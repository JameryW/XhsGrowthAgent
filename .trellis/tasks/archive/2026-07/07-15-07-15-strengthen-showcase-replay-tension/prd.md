# Strengthen showcase and replay narrative tension

## Goal

让展示页与工作流回放页拥有更清晰的阅读顺序和更集中的视觉张力，减少装饰性噪声，强化“当前发生了什么、下一步是什么、最终产出是什么”的叙事。

## Requirements

- 展示页首屏有单一视觉焦点，并能把闭环流程自然引向工作流记录。
- 回放页使用克制的步骤推进动效作为主要叙事线索，当前阶段、已完成阶段和待处理阶段必须可区分。
- 动效不改变真实检查点选择、数据展示和无数据状态；用户可点击任意检查点查看结果。
- 遵循 `prefers-reduced-motion`，不制造持续高频动画或额外网络请求。
- 保持响应式布局、无障碍语义和现有性能预算。

## Acceptance criteria

- 两个页面不存在重复主操作，首屏能快速识别当前状态与主要下一步。
- 回放页在有检查点时呈现稳定、轻量、可理解的进度动效；无检查点时呈现清晰的静态引导。
- `npm run type-check`、`npm run build`、`npm test -- --run`、`git diff --check` 全部通过。
