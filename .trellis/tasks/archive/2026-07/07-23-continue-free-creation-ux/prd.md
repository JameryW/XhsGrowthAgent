# PRD: 继续优化自由创作交互体验

## 背景

自由创作入口已经具备 Agent 连接状态、断线消息队列和快捷操作，但在网络抖动或首次使用时仍有两个可感知问题：

1. WebSocket 在生成过程中断开并重连后，终端可能继续显示处理中，用户无法判断是否可以继续输入。
2. 断线时点击“新会话”无法保留意图，之前暂存的消息还可能进入新会话，造成上下文混淆。
3. 首次进入只有命令列表，用户仍需要自己组织第一句话，未充分利用自由创作的自然语言入口。

## 目标

- 让连接恢复后的输入状态与实际可用状态一致，并明确提示被中断的生成。
- 让“新会话”成为可恢复的用户意图：断线时先暂存，重连后优先创建新会话，再发送用户在新会话之后输入的内容；旧队列不跨越新会话。
- 在不替用户自动发起创作请求的前提下，提供可编辑的自然语言示例，降低首次使用门槛。

## 范围

### 包含

- `frontend/src/views/AgentTUI.vue` 的自由模式 WebSocket 生命周期、消息队列和首次使用快捷示例。
- 中英文 TUI 文案。
- AgentTUI 自由模式交互回归测试。
- 自由创作规范中的状态与队列契约。

### 不包含

- 后端 Agent 协议或自由创作工具行为。
- 固定工作流模式的业务流程。
- 跨页面、跨账号持久化消息。

## 验收标准

1. Agent 正在生成时连接断开，界面会结束当前“处理中”状态并提示本轮可能被中断；重连后用户可以继续输入。
2. 断线时触发 `/start` 或点击“新会话”，会清除旧的暂存自然语言消息，并保留新会话意图。
3. 重连成功后，如果存在新会话意图，发送顺序固定为 `new_session` → 新会话之后暂存的自然语言消息。
4. 自由模式提供至少三个自然语言示例按钮；点击只将示例填入当前输入框，不直接提交，用户可编辑后发送。
5. 移动端点击示例后，示例进入移动输入框；桌面端示例进入终端输入行并保持焦点。
6. 中英文 key 保持一致，类型检查、测试和生产构建通过。
