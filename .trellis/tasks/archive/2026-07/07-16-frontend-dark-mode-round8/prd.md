# 修复暗黑模式切换卡顿

## 背景

点击 ThemeToggle 后，页面切换到浅色/暗黑模式的反馈明显延迟。当前主题切换会给 html 增加/移除 dark class，而 frontend/src/styles/main.css 包含大量 html.dark [class*="..."] 全局属性选择器；页面元素越多，浏览器重新匹配这些选择器的成本越高。

## 目标

- 让点击主题切换后尽快完成视觉反馈，避免整页出现明显卡顿。
- 保留现有浅色/暗黑模式的颜色层级、表单可读性和组件兼容性。
- 不改变 light / dark / system 偏好持久化及系统主题监听行为。
- 不引入全局动画闪烁；主题切换时只有必要的控件状态过渡。

## 验收标准

1. 主题切换逻辑仍能正确更新 dark class、data-theme、color-scheme 和本地存储。
2. 暗黑模式下现有核心页面/弹层/表单仍保持可读，不因性能优化恢复大面积白色表面。
3. 主题切换相关测试和前端 type-check/build 通过。
4. CSS 主题覆盖不再依赖不必要的大量通配属性选择器；切换时的样式重算范围和规则复杂度有明确下降。
