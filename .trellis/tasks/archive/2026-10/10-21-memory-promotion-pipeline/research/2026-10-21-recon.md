# 侦察记录（2026-10-21）—— Memory Promotion Pipeline 的现状与缺口

方法：只读代码/文档，逐条给出出处；没有估算，没有"应该存在"的假设。
所有行号以 2026-10-21 的 `main`（squash `6e3771bc` 之后）为准。

## A. hy-memory（外部引擎）

| 事实 | 出处 |
|---|---|
| 可选增强层，默认关；SDK 未装/端点超时/结构异常全部降级，永不炸调用方 | `docs/hy-memory.md` §1（契约表）；`backend/memory/hy/bridge.py` |
| `recall` / `remember` / `forget` / `list_memories` / `metrics` / `health` 全是 async、永不抛 | `bridge.py:192`（recall）、`:234`（remember）、`:305`（forget）、`:78`（health）、`:319`（metrics） |
| 故障与"没命中"靠 `last_error()` 区分；成功即清除 | `bridge.py:74`；`docs/hy-memory.md` §2.1 |
| `HYMEMORY_MODE=pro` 时 LLM 抽取与冲突调和发生在 **SDK 内部**（reconciler），仓库看不到 | `docs/hy-memory.md` §4（MODE 说明） |
| 召回适配器有三态：`EMPTY` / `HIT` / `DEGRADED`，降级在 prompt 里显式标注 | `backend/memory/hy/recall.py`；`docs/hy-memory.md` §2.2 |
| 写入只带调用方给的 metadata（`kind`/`post_id`/`niche`），没有任何验证 | `backend/agents/analyst.py` 的 `_safe_remember_hy`；`docs/hy-memory.md` §3 |

**结论**：SDK 的抽取器是**候选生成器**；仓库没有任何"这条候选可不可信/是否重复/该不该进 prompt"的判断。

## B. `MemoryManager`（仓库自有长期记忆）

| 事实 | 出处 |
|---|---|
| 四个命名空间：content_history / audience_preferences / performance_insights / strategy_notes | `backend/memory/store.py:39-57` |
| 四个写入方法都 `store.aput(key=uuid4(), value=record)`：只追加、不看已有 | `store.py:61-87` |
| 四个 recall 在票 5m 后"失败即抛"，`[]` 只表示确实没有 | `store.py:89-95` 注释 + 4 个方法 |

**结论**：没有 verify、没有 dedupe、没有 supersede、没有决定记录；同一结论可以多条并存。

## C. Creative Memory（实测行 + 合并原语）

| 事实 | 出处 |
|---|---|
| 行级实测：`engagement_rate` / `sample_count` / `proven_count` / `source_post_id` 等 | `backend/memory/creative.py`；`docs/creator-agent.md` §"从 Creative Memory 生成 Evidence 提案" |
| `deposit_style`：按 tone+visual 精确匹配已有风格 → `_merge_style` 加权平均 + 累加 sample_count（DB 合并锁 + 事务） | `creative.py:289-314`、`:539-564` |
| `deposit_play` / `deposit_material` 直接 upsert；四者失败均 `logger.warning` 吞掉（**写入侧 best-effort**） | `creative.py:313-314`、`:316-338` |
| `_find_similar_style` 的 store 回退是精确 tone+visual 过滤，不是语义合并 | `creative.py:508-536` |

"样本够不够格变成策略结论"没有闸门。

## D. Creator Agent（审查/学习路径）

| 事实 | 出处 |
|---|---|

**结论**：审查基础设施已存在，但服务对象是 **Creator Model**；没有任何东西记录

## E. Context Compiler provenance（可复用的词表）

| 事实 | 出处 |
|---|---|
| `TrustClass`：`internal_fact` / `memory` / `external_document` / `model_generated` / `unspecified` | `backend/context/models.py:52-78` |
