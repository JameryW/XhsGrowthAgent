# 暗黑模式支持 PRD

## 背景

当前前端界面以浅色玻璃拟态为主，展示页和回放页在低光环境下对比度偏高，且没有跨页面保存主题偏好的能力。需要提供可访问、可持久化的暗黑模式，同时保持现有信息架构和品牌强调色。

## 目标

- 支持浅色 / 暗色切换，首次访问沿用系统偏好，并在后续访问中恢复用户选择。
- 在应用启动阶段提前应用主题，避免首页或展示页先闪现浅色再切换。
- 为全局背景、玻璃面板、文字、边框、表单控件和滚动条提供深色 token，覆盖工作台、展示页和回放模式。
- 在公开页面和登录后工作台提供可发现、可键盘操作且有本地化标签的主题切换入口。

## 非目标

- 不重做页面布局、品牌强调色或动画体系。
- 不把主题偏好写入后端账号配置；主题只属于当前浏览器。

## 验收标准

1. 用户点击主题按钮后，页面在无需刷新情况下切换到暗色 / 浅色，按钮具备 `aria-label` 和至少 44px 触控区域。
2. 主题偏好写入 `localStorage`；没有用户选择时读取 `prefers-color-scheme`，系统偏好变化时跟随系统。
3. 刷新首页、展示页、回放页或登录页时，首屏不会出现明显的浅色闪烁；`color-scheme` 与根节点主题状态一致。
4. 暗色下主要工作区、展示内容、回放结果、导航、弹层、输入控件和错误/空状态具备可读对比度，移动端不产生横向溢出。
5. 中英文主题标签齐全，类型检查、单元测试和生产构建通过。
