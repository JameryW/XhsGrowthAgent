# 前端交互体验优化

## 目标

把当前前端从“模块可用”提升为“路径连贯、状态清晰、移动端可操作”的体验，重点消除死链、错误恢复误操作、重复状态提示和移动端功能缺失，并降低创作、审核与增长页面的认知负担。

## 范围

1. 修复帮助中心、移动端导航、路由深链、登出反馈、历史空状态和仪表盘重试等明确交互缺陷。
2. 统一在线/离线状态与全局账号上下文，避免重复提示和错误账号操作。
3. 简化创作启动流程，增加下一步动作提示；让审核操作更聚焦；为自由创作保留终端能力同时提供引导入口。
4. 优化设置、增长/评估页面的响应式、空状态、数据新鲜度和操作反馈。
5. 补齐中英文文案、键盘/焦点、触控尺寸、减少动画和回归测试。

## 完成标准

- 所有主导航与帮助入口都能到达真实页面或真实面板，不再出现死链/错绑动作。
- 移动端可访问工作台、创作、审核、增长、历史和设置，并能看到当前账号上下文。
- 重试只刷新当前数据，不会隐式创建新工作流；登出、空状态、网络状态反馈准确且不重复。
- 创作、审核、设置关键路径在窄屏下无横向溢出，主要动作触控区域不小于 44px。
- `npm run type-check`、`npm run build`、前端测试和 diff 检查通过。
- README、前端交互说明和对应 Trellis 规范同步记录新的路由、状态与可访问性约定。
