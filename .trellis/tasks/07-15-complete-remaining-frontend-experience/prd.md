# 完成剩余前端体验优化

## 背景

前两轮优化已经改善了工作台和创作页的状态表达，但桌面左侧导航仍保持旧版布局，导致全局入口、当前上下文和产品层级不明显。用户反馈“页面没有大的变化”，本任务补齐导航及其相关的全局体验缺口。

## 目标

- 让桌面导航成为清晰的产品工作区：品牌、当前阶段、账号上下文、主入口和辅助入口有明确层级。
- 让当前页面、待处理状态和连接状态可以一眼识别；不依赖颜色单独表达状态。
- 保持平板折叠导航、移动端底部导航和现有路由语义一致。
- 保持所有新增文案双语、键盘可达、主要操作至少 44px，并兼容 reduced-motion。

## 范围

1. 重构 `Navbar.vue` 的桌面/平板视觉层级、分组、活动态、账号上下文和底部工具区。
2. 统一 `MobileTabBar.vue` 的活动态、更多菜单和账号/连接信息表达，避免桌面与移动端优先级漂移。
3. 补齐中英文导航文案和组件测试，更新前端交互说明。
4. 通过类型检查、前端测试、生产构建和 diff 检查。

## 非目标

- 不修改后端接口、工作流状态语义或路由地址。
- 不替换全局视觉主题；只提升导航区域的层级、状态和可见性。

## 验收标准

- 已登录桌面工作区显示品牌区、工作区状态、开始创作主行动、分组导航、当前账号卡片和工具入口。
- 当前路由有明确活动态，待审核/待处理阶段有可访问的状态提示；活动态不只依赖颜色。
- 平板折叠状态保留图标、tooltip/aria-label 和状态指示；移动端保留创作、工作台、审核及更多入口。
- 新增文案同时存在于 `en.json` 与 `zh-CN.json`，主要按钮触控高度不小于 44px，动画支持 `prefers-reduced-motion`。
- `npm run type-check`、`npm run test:run`、`npm run build` 和 `git diff --check` 通过。
