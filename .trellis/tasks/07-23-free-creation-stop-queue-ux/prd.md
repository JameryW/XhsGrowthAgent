# PRD: 优化自由创作停止生成与队列反馈

## 背景

自由创作入口已经支持断线暂存消息和自动重连，但当前用户仍有两个高频操作缺口：

- 桌面端 Ctrl+C 会发送 abort，但本地可能继续显示“处理中”；移动端没有同等的停止入口。
- 暂存消息数量只在写入终端时提示，终端滚动后用户无法快速判断还有多少内容等待发送。

## 目标

- 为自由创作中的 Agent turn 提供明确、可触达的“停止生成”操作，桌面和移动端行为一致。
- 让 abort 反馈立即反映在本地 UI，不依赖服务端后续事件才解除忙碌状态。
- 在状态栏显示当前暂存消息数量，并在发送、清空和新会话时保持同步。

## 范围

### 包含

- `frontend/src/views/AgentTUI.vue` 的 Agent turn 状态、Ctrl+C、停止按钮和队列计数。
- 中英文 TUI 文案与样式。
- 自由创作交互回归测试和规范更新。

### 不包含

- 后端 abort 协议和 Agent 服务端执行语义。
- 固定工作流业务操作。
- 消息跨页面或跨账号持久化。

## 验收标准

1. 自由模式自然语言消息成功发送后，显示“停止生成”入口；该入口不受普通 `isProcessing` 快捷按钮禁用逻辑影响。
2. 点击停止生成或按 Ctrl+C 会发送 `{type: "abort"}`，立即清除本地 Agent turn/处理中状态并展示本地化反馈；连接不可用时也不会留下卡死的 spinner。
3. Agent 收到 `status=running`、`status=idle`、完成、错误、会话结束或断线事件时，Agent turn 状态保持同步。
4. 自由模式断线队列有 1 条或更多消息时，状态栏显示数量；消息被发送或因新会话清空后，数量同步归零。
5. 固定工作流模式的 slash command、API 调用和连接行为不改变。
6. 中英文 key 保持一致，类型检查、测试和生产构建通过。
