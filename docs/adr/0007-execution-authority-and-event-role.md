# Execution authority stays with the checkpoint; events stay telemetry

Recovery authority belongs to the LangGraph checkpoint and the artifact store. The workflow Event store is an observation and audit timeline with a best-effort write contract (`backend/state/events.py`: emitting is telemetry, nothing may fail because an event was not stored); it must never become a recovery input. This keeps one authoritative state owner per concern — checkpoint for lifecycle, artifacts for results, events for observation, the graph store for external-effect idempotency keys — at the cost of not being able to rebuild a run from events alone. The trade is deliberate: making events recoverable would turn a dropped telemetry row into an unrecoverable run, which is a worse failure mode than losing an audit line. Any future proposal that reads events to restore workflow state must supersede this record first.
